# Deep Reinforcement Learning for Trading 详细总结

论文链接: https://arxiv.org/abs/1911.10107  
论文题目: Deep Reinforcement Learning for Trading  
作者: Zihao Zhang, Stefan Zohren, Stephen Roberts  
机构: Oxford-Man Institute of Quantitative Finance, University of Oxford  
提交时间: 2019-11-22  
研究对象: 50 个高流动性连续期货合约  
测试区间: 2011-2019  

## 1. 论文核心问题

这篇论文研究如何用深度强化学习直接生成交易策略。传统量化交易常见流程是：

```text
市场数据 -> 预测未来收益/方向 -> 人工规则转换成交易信号 -> 下单
```

论文认为这个流程存在一个关键问题：预测未来收益并不等于能形成好的交易仓位。即使模型能预测短期涨跌，如果仓位切换过于频繁，交易成本也会吞掉收益。

因此，作者把问题改成：

```text
市场状态 -> 强化学习策略 -> 目标仓位
```

也就是说，模型不只是预测价格方向，而是直接学习当前应该持有多头、空头、空仓，或者多大的连续仓位。

论文重点研究三个问题：

1. 离散动作空间和连续动作空间哪个更适合交易。
2. 奖励函数中加入波动率缩放后，是否能提升稳健性。
3. 在包含交易成本的情况下，深度 RL 是否能优于传统时间序列动量策略。

## 2. 使用的方法

论文使用三类深度强化学习方法。

### 2.1 DQN

DQN 用于离散动作空间。模型学习动作价值函数：

```text
Q(s_t, a_t)
```

给定当前市场状态 `s_t`，DQN 估计选择每个动作 `a_t` 的长期价值，然后选择价值最大的动作。

论文中 DQN 的动作是：

```text
A_t in {-1, 0, 1}
```

含义：

- `-1`: 最大做空。
- `0`: 空仓。
- `1`: 最大做多。

论文还使用了 DQN 的稳定化技巧：

- fixed Q-target: 使用目标网络减少训练震荡。
- Double DQN: 降低 Q 值过估计。
- Dueling DQN: 分离状态价值和动作优势，提高学习效率。

### 2.2 Policy Gradient

Policy Gradient 直接学习策略：

```text
pi(a_t | s_t)
```

它不是先估计每个动作的 Q 值，而是直接输出动作概率。优点是形式直接，缺点是方差较大，训练效率通常低于 actor-critic。

论文中 Policy Gradient 也用于离散动作空间：

```text
A_t in {-1, 0, 1}
```

### 2.3 A2C

A2C 是 actor-critic 方法：

- Actor: 输出动作策略。
- Critic: 估计状态价值。
- Advantage: 用实际收益和价值估计之间的差值降低梯度方差。

论文中 A2C 用于连续动作空间：

```text
A_t in [-1, 1]
```

含义：

- `1`: 满仓做多。
- `0.5`: 半仓做多。
- `0`: 空仓。
- `-0.5`: 半仓做空。
- `-1`: 满仓做空。

A2C 的连续动作更灵活，但也更容易产生频繁的小幅调仓，因此交易成本控制更重要。

## 3. 数据和交易环境设置

### 3.1 数据来源

论文使用 Pinnacle Data Corp CLC Database 中的 ratio-adjusted continuous futures contracts。

原始数据范围：

```text
2005-2019
```

样本外测试范围：

```text
2011-2019
```

资产包括 50 个高流动性期货合约，覆盖四大类别：

- Commodities: 25 个。
- Equity indices: 11 个。
- Fixed income: 5 个。
- FX: 9 个。

这些市场选择很重要，因为期货可以较方便地做多和做空，也适合测试趋势跟踪策略。

### 3.2 训练和测试方式

论文没有使用随机切分，而是使用时间序列式训练和测试。

大致流程：

1. 用历史数据训练模型。
2. 固定模型参数。
3. 在未来样本外区间测试。
4. 每 5 年重新训练一次。

这种方式比随机 train/test split 更合理，因为金融数据有时间顺序。随机切分会让未来信息泄漏到训练集中。

### 3.3 环境中的账户和仓位

论文不是模拟一个复杂券商账户，而是把每个期货合约视为一个独立交易环境。模型在每个时间点输出目标仓位 `A_t`。

交易收益来自：

```text
上一期仓位 * 本期价格变化
```

交易成本来自：

```text
当前目标仓位和上一期目标仓位之间的变化
```

因此，如果模型一直持有同一方向，不会反复产生交易成本；如果模型频繁从多头切换到空头，则成本很高。

## 4. 状态空间设置

每个时间步，模型观察过去 60 个时间点的特征。状态主要由价格、动量、技术指标和波动率归一化变量组成。

### 4.1 价格和收益特征

状态中包含归一化价格序列，以及多个周期的收益：

- 过去 1 个月收益。
- 过去 2 个月收益。
- 过去 3 个月收益。
- 过去 1 年收益。

这些特征用于捕捉时间序列动量。期货市场中，趋势跟踪和动量策略是非常经典的基线。

### 4.2 波动率归一化收益

论文不直接使用原始收益，而会使用波动率归一化后的收益特征。例如一年收益会除以年化波动率：

```text
normalized_return = return / (sigma_t * sqrt(252))
```

其中 `sigma_t` 是事前波动率估计，通常用指数加权移动标准差计算。

这样做的目的：

- 不同合约的波动水平不同，需要统一尺度。
- 高波动时期的原始收益不一定代表更强信号。
- 便于模型在不同资产类别之间学习更稳定的模式。

### 4.3 MACD 特征

论文使用多组 MACD 指标。MACD 本质上刻画短期均线和长期均线的差异，用于识别趋势强弱和趋势变化。

MACD 在本论文中主要承担两个作用：

- 捕捉中短期趋势。
- 作为传统技术分析基线和 RL 状态输入的一部分。

### 4.4 RSI 特征

论文也使用 RSI 指标，窗口为 30 日。

RSI 用于刻画超买和超卖状态。相比动量特征，RSI 更偏反转或震荡区间识别。

### 4.5 状态设计的特点

这篇论文的状态空间主要是技术面状态，没有加入：

- 基本面数据。
- 新闻情绪。
- 宏观数据。
- 持仓报告。
- 期限结构特征。
- 订单簿特征。

因此，它更像是一个技术分析和趋势跟踪框架下的 RL 交易实验。

## 5. 动作空间设置

论文的一个重要贡献是同时测试离散动作和连续动作。

### 5.1 离散动作

离散动作定义为：

```text
A_t in {-1, 0, 1}
```

含义：

- `-1`: 满仓做空。
- `0`: 空仓。
- `1`: 满仓做多。

需要注意，这里的动作不是“买、卖、持有指令”，而是“目标仓位”。例如：

- 上一期是 `1`，本期还是 `1`: 继续持有多头，不交易。
- 上一期是 `0`，本期是 `1`: 从空仓变为多头，产生买入交易。
- 上一期是 `1`，本期是 `-1`: 从多头变为空头，产生更大的换仓成本。

这种设计比简单的 buy/sell/hold 更适合交易系统，因为它可以自然计算仓位变化和交易成本。

### 5.2 连续动作

连续动作定义为：

```text
A_t in [-1, 1]
```

含义：

- `1`: 最大多头。
- `0`: 空仓。
- `-1`: 最大空头。
- 中间值表示部分仓位。

连续动作的优势：

- 可以表达不确定性。
- 可以逐步加仓或减仓。
- 可以降低 all-in/all-out 的跳跃式交易。

连续动作的风险：

- 动作空间更难学习。
- 容易产生频繁的小调仓。
- 如果奖励中交易成本不够强，模型可能过度交易。

## 6. 奖励函数设置

奖励函数是这篇论文最关键的部分。作者使用的是带波动率缩放和交易成本的收益奖励。

### 6.1 基础收益

如果不考虑缩放和成本，最简单的交易收益是：

```text
R_t = A_{t-1} * r_t
```

其中：

- `A_{t-1}`: 上一期仓位。
- `r_t`: 本期价格变化。

也就是说，本期收益由上一期持有的仓位决定。这符合真实交易：你今天的收益来自昨天收盘后持有到今天的仓位，而不是今天刚刚决定的仓位。

### 6.2 波动率缩放

论文加入波动率缩放：

```text
scaled_position_t = A_t * sigma_target / sigma_t
```

其中：

- `A_t`: 模型输出的目标仓位。
- `sigma_target`: 目标波动率。
- `sigma_t`: 当前估计波动率。

逻辑：

- 当市场波动率高时，`sigma_target / sigma_t` 变小，仓位自动降低。
- 当市场波动率低时，仓位可以相对放大。

这样做的好处：

- 控制不同资产和不同时期的风险暴露。
- 防止模型在高波动阶段承担过大风险。
- 让不同期货合约的收益更可比。

### 6.3 交易成本

论文显式扣除交易成本。交易成本和仓位变化幅度成正比：

```text
cost_t = bp * price_{t-1} * abs(scaled_position_{t-1} - scaled_position_{t-2})
```

其中：

- `bp`: 每次交易成本，以 basis point 表示。
- `price_{t-1}`: 上一期价格。
- `scaled_position`: 波动率缩放后的实际仓位。

如果模型不调仓，成本接近 0。  
如果模型从满多变满空，成本最大。  
如果模型只是小幅调整连续仓位，成本较小。

### 6.4 完整奖励的直观形式

可以把论文奖励理解为：

```text
reward =
  波动率缩放后的持仓收益
  - 波动率缩放后的交易成本
```

更直观地写成：

```text
R_t =
  A_{t-1} * (sigma_target / sigma_{t-1}) * r_t
  - cost_rate * abs(
      A_{t-1} * sigma_target / sigma_{t-1}
      - A_{t-2} * sigma_target / sigma_{t-2}
    )
```

这个奖励函数同时处理了三个问题：

1. 方向是否正确。
2. 波动率是否过高。
3. 调仓是否太频繁。

### 6.5 为什么不用普通收益

如果只用：

```text
reward = A_{t-1} * r_t
```

模型可能学到：

- 频繁翻仓。
- 高波动期过大仓位。
- 忽略交易成本。

这类策略在无成本回测中可能很好，但真实交易中容易失败。

### 6.6 为什么不用 Sharpe 作为训练奖励

论文主要用收益型 reward，而不是直接最大化 Sharpe。原因可以理解为：

- Sharpe 需要一段收益序列，不适合单步 reward。
- 窗口太短会非常噪声。
- 窗口太长会导致奖励延迟。
- 标准差很小时容易产生不稳定数值。

更合理的方式是：训练时使用 dense reward，评估时报告 Sharpe、Sortino、Calmar、最大回撤等指标。

## 7. 基线策略

论文比较了 RL 方法和传统时间序列动量策略。

### 7.1 Long Only

永远做多。这个基线在股指期货中通常较强，因为长期样本中股票指数存在权益风险溢价。

但在商品、外汇、利率等市场中，Long Only 不一定有效。

### 7.2 Sign(R)

使用过去一年收益方向决定仓位：

```text
A_t = sign(past_12m_return)
```

如果过去一年上涨，则做多；如果过去一年下跌，则做空。

这是经典时间序列动量策略。

### 7.3 MACD

使用 MACD 信号生成仓位。MACD 策略可以理解为更平滑的趋势跟踪方法。

### 7.4 RL 策略

- DQN: 离散动作。
- Policy Gradient: 离散动作。
- A2C: 连续动作。

## 8. 实验结果

论文将每个合约的交易收益扣除成本后，按等权方式合成为组合收益：

```text
R_portfolio_t = (1/N) * sum_i R_{i,t}
```

评估指标包括：

- 年化收益。
- 年化波动率。
- downside deviation。
- Sharpe ratio。
- Sortino ratio。
- maximum drawdown。
- Calmar ratio。
- 正收益比例。
- 平均盈利 / 平均亏损。

主要结论：

1. RL 方法整体优于传统时间序列动量基线。
2. DQN 在全资产组合上表现最好。
3. A2C 也表现较强，但换手率更高。
4. RL 模型能在较高交易成本下保持正收益。
5. 股指市场中 Long Only 很强，但在商品和外汇中效果较弱。
6. RL 策略能在大趋势中保持仓位，在震荡期缩小仓位或空仓。

论文摘要中明确说明，算法在 50 个高流动性期货合约、2011-2019 样本外测试中，相比传统时间序列动量策略表现更好，并且在重交易成本下仍能获得正收益。

## 9. 论文贡献

这篇论文的主要贡献包括：

1. 直接学习目标仓位，而不是先预测收益再转交易信号。
2. 同时比较离散动作和连续动作。
3. 在奖励函数中加入波动率缩放。
4. 在训练目标中显式加入交易成本。
5. 使用多资产类别和较长样本外区间测试。
6. 与经典时间序列动量策略进行比较。

## 10. 不足之处

### 10.1 交易执行仍然简化

论文虽然加入交易成本，但没有完整模拟：

- 订单簿。
- 滑点动态变化。
- 市场冲击。
- 部分成交。
- 成交量约束。
- 不同交易时段流动性差异。

### 10.2 没有真正做组合层面优化

论文先为每个合约生成交易收益，再等权合成组合。模型本身没有学习资产之间的相关性，也没有直接输出跨资产组合权重。

### 10.3 状态特征偏技术面

论文主要使用价格、动量、MACD、RSI 和波动率，没有加入：

- 基本面。
- 宏观变量。
- 新闻。
- 持仓报告。
- 期限结构。
- 跨市场相关性。

### 10.4 期货结论不能直接迁移到股票

期货和股票有重要差异：

- 期货可以自然做空。
- 有保证金和杠杆。
- 有合约滚动问题。
- 交易时间和流动性结构不同。
- 股票有个股基本面、停牌、财报、涨跌停等额外问题。

因此，这篇论文的方法可以借鉴，但不能把结果直接套到股票市场。

### 10.5 A2C 换手率问题

连续动作理论上更灵活，但论文结果显示 A2C 的换手率较高。说明连续动作如果没有足够的平滑约束和成本惩罚，可能反而更容易频繁交易。

### 10.6 训练频率较低

论文使用每 5 年重新训练一次的设定，能检验长期泛化，但对快速变化的市场可能不够敏感。

## 11. 对当前项目的启发

### 11.1 动作应优先设计为目标仓位或目标权重

不要让 RL 输出“买多少股/卖多少股”作为第一版。更推荐：

```text
action = target_position 或 target_weight
```

单资产：

```text
action in {-1, 0, 1}
```

或：

```text
action in [0, 1]
```

多资产：

```text
action = [w_1, w_2, ..., w_n]
sum(w_i) <= 1
w_i >= 0
```

这样更容易计算换手和交易成本，也更容易对接回测与实盘执行。

### 11.2 奖励必须扣交易成本

推荐基础形式：

```text
r_t = position_{t-1} * return_t
      - cost_rate * abs(position_t - position_{t-1})
```

多资产组合形式：

```text
r_t = portfolio_return_t
      - cost_rate * sum_i abs(w_{t,i} - w^-_{t,i})
```

其中 `w^-_t` 是交易前自然漂移后的权重。

### 11.3 加入波动率缩放

可以借鉴论文的 volatility scaling：

```text
scaled_weight_t = target_weight_t * target_vol / realized_vol_t
```

这样在高波动环境下降仓，在低波动环境允许更高仓位。

### 11.4 避免过度交易

除了成本惩罚，还可以加入：

- 最小持仓时间。
- 最小调仓阈值。
- 目标权重平滑。
- 换手率上限。
- 训练时使用略高于真实交易成本的成本参数。

### 11.5 评估时必须看成本后指标

不要只看 reward 或毛收益。至少报告：

- 扣成本后累计收益。
- 年化收益。
- 年化波动。
- Sharpe。
- Sortino。
- Calmar。
- 最大回撤。
- 交易次数。
- 换手率。
- 成本占收益比例。

## 12. 一句话总结

这篇论文的核心价值在于：它把交易 RL 从“预测涨跌”推进到“直接学习目标仓位”，并通过波动率缩放和交易成本把 reward 设计得更接近真实交易。它证明了在多资产期货市场中，DQN、Policy Gradient、A2C 等深度 RL 方法可以优于传统时间序列动量策略，但其交易执行仍然简化，结论不能直接等同于股票实盘盈利能力。
